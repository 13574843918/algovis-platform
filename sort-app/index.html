① 直接插入排序 (insertSort)

核心思想：将第 i 个记录插入已排好序的前 i-1 个记录中的适当位置，依次扩大有序区。

算法步骤

1
从 i=1 开始，将 r[i] 保存为 tmp
2
若 tmp.price < r[i-1].price，向右移动已排序元素直到找到插入位置
3
将 tmp 插入空位，i 递增，重复直到 i = r.length-1
public void insertSort() {
    for (int i = 1; i < r.length; i++) {
        if (r[i].price < r[i - 1].price) {
            Product tmp = r[i];
            int j = 0;
            for (j = i - 1; j >= 0 && tmp.price < r[j].price; j--) {
                r[j + 1] = r[j];        // 元素后移
            }
            r[j + 1] = tmp;             // 插入到正确位置
        }
    }
}

稳定 ✅ | 时间 O(n²) | 空间 O(1) | 最好情况（已有序）O(n)

② 希尔排序 (shellSort)

核心思想：按增量 d（初始 = n/3）分组做直接插入排序；不断缩小 d，直到 d=1 完成最终排序。

算法步骤

1
计算初始增量 d = r.length / 3
2
按增量 d 对每个子序列做直接插入排序
3
d 递减，重复步骤2；m 从 increment 递减到 1
public void shellSort() {
    int i, j, d;
    Product tmp;
    int increment = r.length / 3;       // 初始增量
    for (int m = increment; m >= 1; m--) {
        d = m;
        for (i = d; i < r.length; i++)
            if (r[i].price < r[i - d].price) {
                tmp = r[i];
                j = i;
                do {
                    r[j] = r[j - d];
                    j = j - d;
                    if (j - d < 0) break;
                } while (j > 0 && tmp.price < r[j - d].price);
                r[j] = tmp;
            }
    }
}

不稳定 ❌ | 时间 O(n^1.3) | 空间 O(1)

③ 直接选择排序 (selectSort)

核心思想：每轮从未排序区找最小元素，与未排序区首元素交换；重复 n-1 轮。

算法步骤

1
从位置 i 开始，设 k=i 为最小值下标
2
遍历 j=i+1 到 n-1，若 r[j].price < r[k].price，则更新 k=j
3
若 k≠i，交换 r[i] 与 r[k]，i 递增
public void selectSort() {
    int k;
    Product tmp;
    for (int i = 0; i < r.length - 1; i++) {
        k = i;                          // 假设当前位置最小
        for (int j = i + 1; j < r.length; j++)
            if (r[j].price < r[k].price)
                k = j;                  // 更新最小值下标
        if (k != i) {
            tmp = r[i]; r[i] = r[k]; r[k] = tmp;  // 交换
        }
    }
}

不稳定 ❌ | 时间 O(n²) | 空间 O(1) | 所有情况相同

④ 堆排序 (heapSort)

核心思想：建大根堆后，反复取堆顶（最大值）与末尾交换，然后对剩余元素重建堆。

createHeap 筛选算法

1
从 high/2 向 low 逐个向下筛选（确保父 ≥ 子）
2
对每个节点 k，找其左右孩子中较大者 j，若 r[k] < r[j]，下移
3
继续向下调整，直到叶节点或无需调整
public void createHeap(int low, int high) {
    if ((low < high) && (high < r.length)) {
        int j = 0, k = 0;
        Product tmp;
        for (int i = high / 2; i >= low; --i) {  // 从最后非叶节点向根
            tmp = r[i]; k = i; j = 2 * k + 1;
            while (j <= high) {
                if ((j < high) && (j+1 <= high) && (r[j].price < r[j+1].price))
                    ++j;                            // 选较大孩子
                if (tmp.price < r[j].price) {
                    r[k] = r[j]; k = j; j = 2*k+1;  // 下移
                } else break;
            }
            r[k] = tmp;
        }
    }
}

public void heapSort() {
    Product tmp;
    createHeap(0, r.length - 1);               // 建初始大根堆
    for (int i = r.length - 1; i > 0; --i) {
        tmp = r[0]; r[0] = r[i]; r[i] = tmp;   // 堆顶与末尾交换
        createHeap(0, i - 1);                   // 重建堆
    }
}

不稳定 ❌ | 时间 O(nlogn) | 空间 O(1) | 堆节点规则（0-indexed）：左孩子=2i+1，右孩子=2i+2

⑤ 冒泡排序 (bubbleSort)

核心思想：相邻元素两两比较，较大者右移（"冒泡"）；若某趟无交换则提前终止。

public void bubbleSort() {
    boolean exchange;
    Product tmp;
    int n = r.length;
    for (int i = 1; i < n; i++) {
        exchange = false;
        for (int j = 0; j < n - i; j++)
            if (r[j].price > r[j + 1].price) {
                tmp = r[j + 1]; r[j + 1] = r[j]; r[j] = tmp;
                exchange = true;
            }
        if (!exchange) break;  // 无交换，提前结束
    }
}

稳定 ✅ | 时间 O(n²) | 空间 O(1) | 最好情况（已有序）O(n)

⑥ 快速排序 (quickSort)

核心思想：取 r[low] 为枢轴 pivot；双指针 i、j 从两端向中间扫描，将小于 pivot 的移到左侧，大于的移到右侧；递归处理两个子序列。

public void quickSort() { quickSort(0, r.length - 1); }

public void quickSort(int low, int high) {
    int pivot = r[low].price;          // 枢轴
    int i = low + 1, j = high;
    Product tmp;
    while (i < j) {
        while ((j > i) && pivot <= r[j].price) { --j; }   // j左移
        while ((i < j) && (pivot >= r[i].price)) { ++i; }  // i右移
        if (i < j) { tmp = r[i]; r[i] = r[j]; r[j] = tmp; }  // 交换
    }
    if (r[j].price < r[low].price) {  // pivot归位
        tmp = r[low]; r[low] = r[j]; r[j] = tmp;
    }
    if (i - low > 1) quickSort(low, i - 1);
    if (high - j > 1) quickSort(j + 1, high);
}

不稳定 ❌ | 平均 O(nlogn) | 最坏 O(n²) | 空间 O(logn)

⑦ 归并排序 (mergeSort)

核心思想：自底向上，将相邻有序子序列两两归并；每趟归并后子序列长度加倍。

public void mergeSort() {
    int k = 1;
    while (k < r.length) { merge(k); k *= 2; }  // k: 1,2,4,8...
}

public void merge(int len) {
    int m=0, l1=0, h1, l2, h2, i=0, j=0;
    Product[] tmp = new Product[r.length];
    while (l1 + len < r.length) {
        l2 = l1 + len;  h1 = l2 - 1;
        h2 = (l2 + len - 1 < r.length) ? l2 + len - 1 : r.length - 1;
        i = l1; j = l2;
        while (i <= h1 && j <= h2) {
            if (r[i].price <= r[j].price) tmp[m++] = r[i++];
            else                           tmp[m++] = r[j++];
        }
        while (i <= h1) tmp[m++] = r[i++];
        while (j <= h2) tmp[m++] = r[j++];
        l1 = h2 + 1;
    }
    i = l1; while (i < r.length) tmp[m++] = r[i++];
    for (i = 0; i < r.length; ++i) r[i] = tmp[i];
}

稳定 ✅ | 时间 O(nlogn) | 空间 O(n)（需辅助数组）

⑧ 基数排序 (radixSort)

核心思想：利用链式桶（RadixNode），从最低位（个位）到最高位依次"分配"入桶，再"收集"；共 d 轮（d为最大值位数）。

static class RadixNode {
    public Product data;
    public RadixNode next;
}

public void radixSort() {
    int k, l, power;
    RadixNode p, q;
    RadixNode[] head = new RadixNode[10];
    power = 1;
    int max = r[0].price;
    for (int i = 1; i < r.length; i++)
        if (r[i].price > max) max = r[i].price;
    int d = 0;
    while (max > 0) { d++; max /= 10; }  // 计算位数
    for (int i = 0; i < d; i++) {
        if (i == 0) power = 1; else power = power * 10;
        for (int j = 0; j < 10; j++) head[j] = new RadixNode(); // 初始化桶
        for (int j = 0; j < r.length; j++) {               // 分配入桶
            k = r[j].price / power - (r[j].price / (power * 10)) * 10;
            q = new RadixNode(); q.data = r[j]; q.next = null;
            p = head[k].next;
            if (p == null) head[k].next = q;
            else { while (p.next != null) p = p.next; p.next = q; }
        }
        l = 0;
        for (int j = 0; j < 10; j++) {                        // 收集
            p = head[j].next;
            while (p != null) { r[l] = p.data; l++; p = p.next; }
        }
    }
}

稳定 ✅ | 时间 O(d(n+r)) | 空间 O(n+r) | 桶数 r=10（十进制），d 为最大值位数

📖 排序的基本概念

定义：将一组"无序"的记录序列调整为"有序"的记录序列，使之按关键字值（递增或递减）依次排列。


形式化描述：
• 含n个记录的序列：{ R₁, R₂, …, Rₙ }
• 对应关键字序列：{ K₁, K₂, …, Kₙ }
• 排序结果满足：Kp₁ ≤ Kp₂ ≤ … ≤ Kpₙ

⚖️ 稳定性分析

稳定排序：若两个记录关键字相等，排序后它们的相对顺序不变。


稳定不稳定
直接插入排序（r[i].price ≤ r[j].price 时不移动）
冒泡排序（相等时不交换）
归并排序（合并时 r[i].price ≤ r[j].price 优先取左）
基数排序（按桶收集保持相对顺序） 		希尔排序（跨越多个位置的元素移动）
直接选择排序（交换可能跳过相等元素）
堆排序（堆的建立破坏相对顺序）
快速排序（划分时可能改变相等元素顺序）
