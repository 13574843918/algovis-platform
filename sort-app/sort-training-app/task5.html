1 算法原理

冒泡排序从前往后比较相邻元素，如果顺序错误就交换。通过多次遍历，将最大的元素逐步"冒泡"到数组末端。

教材实现了一个提前终止优化：使用 exchange 标志，如果某一轮没有发生任何交换，说明数组已经有序，可以提前结束。

时间复杂度：O(n²)，空间复杂度：O(1)，是稳定的排序算法。

3 Java代码实现

// 冒泡排序（带提前终止优化）  时间: O(n²)  空间: O(1)  稳定: 是
public void bubbleSort() {
    boolean exchange;
    Product tmp;
    int n = r.length;
    for (int i = 1; i < n; i++) {
        exchange = false;
        for (int j = 0; j < n - i; j++) {
            if (r[j].price > r[j + 1].price) {
                tmp = r[j + 1];
                r[j + 1] = r[j];
                r[j] = tmp;
                exchange = true;
            }
        }
        if (!exchange) break;
    }
}

关键点：

  • 第 i 轮后，最大的 i 个元素已在正确位置
  • exchange 标志用于提前终止
  • 内层循环范围：j = 0 到 n-i-1

2. 提前终止优化的作用是什么？

提前终止优化可以减少不必要的比较。当某一轮排序中没有任何交换发生时，说明数组已经有序，可以 break 提前终止。

💡 提示

冒泡排序的提前终止优化使得最好情况下时间复杂度可达到 O(n)（当数组已经有序时，只需一轮比较）。
