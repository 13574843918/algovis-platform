1 算法原理

直接插入排序（Insert Sort）是一种简单的排序算法，核心思想是：将数组分为"有序区"和"无序区"，每次取无序区第一个元素，在有序区从后向前查找插入位置。

将待插入元素缓存到临时变量 tmp 中，然后在循环中移动元素，最后将 tmp 插入到正确位置。

时间复杂度：O(n²)，空间复杂度：O(1)，是稳定的排序算法。

/** 直接插入排序 时间复杂度: O(n²) 空间: O(1) 稳定: 是 */
public void insertSort() {
    for (int i = 1; i < r.length; i++) {
        if (r[i].price < r[i - 1].price) {
            Product tmp = r[i];
            int j = 0;
            for (j = i - 1; j >= 0 && tmp.price < r[j].price; j--) {
                r[j + 1] = r[j];
            }
            r[j + 1] = tmp;
        }
    }
}

关键点：

  • 只有当 r[i].price < r[i-1].price 时才需要插入
  • 循环条件 j >= 0 && tmp.price < r[j].price
  • 插入位置是 j+1

2. 直接插入排序是稳定的排序算法吗？为什么？

是稳定排序。因为算法只进行"<"比较，当 tmp.price == r[j].price 时不满足 tmp.price < r[j].price，循环终止，tmp 插入到相等元素之后，不改变相等元素的相对顺序。

1 算法原理

希尔排序（Shell Sort）是插入排序的改进版，核心思想是：设置一个增量序列 d，将数组按间隔 d 分成若干组，对每组进行直接插入排序；然后缩小增量，重复上述过程，直到增量 d=1。

时间复杂度：O(n^(1.3~1.5))，空间复杂度：O(1)，是不稳定的排序算法。

/** 希尔排序 时间复杂度: O(n^1.3~1.5) 空间: O(1) 稳定: 否 */
public void shellSort() {
    int i, j, d; Product tmp;
    int increment = r.length / 3;
    for (int m = increment; m >= 1; m--) {
        d = m;
        for (i = d; i < r.length; i++) {
            if (r[i].price < r[i - d].price) {
                tmp = r[i]; j = i;
                do {
                    r[j] = r[j - d]; j = j - d;
                    if (j - d < 0) break;
                } while (j > 0 && tmp.price < r[j - d].price);
                r[j] = tmp;
            }
        }
    }
}
  • 外层循环控制增量递减：d = m, m/3, m/9, ... , 1
  • 使用 do-while 而不是 for
  • j - d < 0 的判断防止越界

/** 直接选择排序 时间复杂度: O(n²) 空间: O(1) 稳定: 否 */
public void selectSort() {
    int k; Product tmp;
    for (int i = 0; i < r.length - 1; i++) {
        k = i;
        for (int j = i + 1; j < r.length; j++) {
            if (r[j].price < r[k].price) k = j;
        }
        if (k != i) {
            tmp = r[i]; r[i] = r[k]; r[k] = tmp;
        }
    }
}
  • k 记录最小值索引
  • 内层循环在无序区 [i+1, n-1] 中找最小值

1 算法原理

堆排序基于大根堆（父节点大于等于子节点）。分为两个阶段：建堆（从最后一个非叶子节点开始调整）和排序（交换堆顶与堆尾，重新建堆）。

时间复杂度：O(n log n)，空间复杂度：O(1)，是不稳定的排序算法。

2 堆的存储结构

  • 节点 i 的左子节点：2*i + 1
  • 节点 i 的右子节点：2*i + 2
  • 节点 i 的父节点：(i - 1) / 2
  • 最后一个非叶子节点：⌊n/2⌋ - 1

/** 堆排序 时间复杂度: O(nlogn) 空间: O(1) 稳定: 否 */
public void createHeap(int low, int high) {
    if ((low < high) && (high < r.length)) {
        int j, k; Product tmp;
        for (int i = high / 2; i >= low; --i) {
            tmp = r[i]; k = i; j = 2 * k + 1;
            while (j <= high) {
                if ((j < high) && (j + 1 <= high) && (r[j].price < r[j + 1].price)) ++j;
                if (tmp.price < r[j].price) {
                    r[k] = r[j]; k = j; j = 2 * k + 1;
                } else break;
            }
            r[k] = tmp;
        }
    }
}
public void heapSort() {
    Product tmp;
    createHeap(0, r.length - 1);
    for (int i = r.length - 1; i > 0; --i) {
        tmp = r[0]; r[0] = r[i]; r[i] = tmp;
        createHeap(0, i - 1);
    }
}

/** 冒泡排序（带提前终止优化） 时间: O(n²) 空间: O(1) 稳定: 是 */
public void bubbleSort() {
    boolean exchange; Product tmp;
    int n = r.length;
    for (int i = 1; i < n; i++) {
        exchange = false;
        for (int j = 0; j < n - i; j++) {
            if (r[j].price > r[j + 1].price) {
                tmp = r[j + 1]; r[j + 1] = r[j]; r[j] = tmp;
                exchange = true;
            }
        }
        if (!exchange) break;
    }
}

/** 快速排序 时间: O(nlogn) 空间: O(logn) 稳定: 否 */
public void quickSort() { quickSort(0, r.length - 1); }
private void quickSort(int low, int high) {
    int pivot = r[low].price;
    int i = low + 1, j = high; Product tmp;
    while (i < j) {
        while ((j > i) && (pivot <= r[j].price)) --j;
        while ((i < j) && (pivot >= r[i].price)) ++i;
        if (i < j) { tmp = r[i]; r[i] = r[j]; r[j] = tmp; }
    }
    if (r[j].price < r[low].price) { tmp = r[low]; r[low] = r[j]; r[j] = tmp; }
    if (i - low > 1) quickSort(low, i - 1);
    if (high - j > 1) quickSort(j + 1, high);
}
  • 基准选择区间第一个元素
  • i 从 low+1 向右，j 从 high 向左，双指针同时移动
  • 退出外层 while 后，需要将基准放到正确位置

1 归并排序原理

归并排序采用分治策略：先将数组分成两半，分别排序后再合并成一个有序数组。

关键操作：两路归并——将两个有序数组合并为一个有序数组。

时间复杂度：O(n log n)，空间复杂度：O(n)，是稳定的排序算法。

2 归并排序 Java代码

/** 归并排序 时间: O(nlogn) 空间: O(n) 稳定: 是 */
public void mergeSort() {
    int k = 1;
    while (k < r.length) { merge(k); k *= 2; }
}
public void merge(int len) {
    int m = 0, l1 = 0, h1, l2, h2, i, j;
    Product[] tmp = new Product[r.length];
    while (l1 + len < r.length) {
        l2 = l1 + len; h1 = l2 - 1;
        h2 = (l2 + len - 1 < r.length) ? l2 + len - 1 : r.length - 1;
        i = l1; j = l2;
        while ((i <= h1) && (j <= h2)) {
            if (r[i].price <= r[j].price) tmp[m++] = r[i++];
            else tmp[m++] = r[j++];
        }
        while (i <= h1) tmp[m++] = r[i++];
        while (j <= h2) tmp[m++] = r[j++];
        l1 = h2 + 1;
    }
    i = l1; while (i < r.length) tmp[m++] = r[i++];
    for (i = 0; i < r.length; ++i) r[i] = tmp[i];
}

3 基数排序原理

基数排序是多关键字排序，按照"个位→十位→百位"的顺序逐位分配和收集。

核心操作：分配（按当前位数字放入对应桶）和收集（按桶顺序取出所有元素）。

时间复杂度：O(d(n+r))，空间复杂度：O(n+r)，是稳定的排序算法。

4 基数排序 Java代码

/** 基数排序 时间: O(d(n+r)) 空间: O(n+r) 稳定: 是 */
public void radixSort() {
    int k, power; RadixNode p, q;
    RadixNode[] head = new RadixNode[10];
    power = 1;
    int max = r[0].price;
    for (int i = 1; i < r.length; i++) if (r[i].price > max) max = r[i].price;
    int d = 0; while (max > 0) { d++; max /= 10; }
    for (int i = 0; i < d; i++) {
        for (int j = 0; j < 10; j++) head[j] = new RadixNode();
        for (int j = 0; j < r.length; j++) {
            k = r[j].price / power - (r[j].price / (power * 10)) * 10;
            q = new RadixNode(); q.data = r[j]; q.next = null;
            p = head[k].next;
            if (p == null) head[k].next = q;
            else { while (p.next != null) p = p.next; p.next = q; }
        }
        int l = 0;
        for (int j = 0; j < 10; j++) {
            p = head[j].next;
            while (p != null) { r[l++] = p.data; p = p.next; }
        }
        power *= 10;
    }
}
static class RadixNode { public Product data; public RadixNode next; }

6 实操练习

1. 归并排序和快速排序都是分治策略，它们的主要区别是什么？

主要区别：

  • 分的方式：快速排序就地划分，通过基准划分左右两部分；归并排序对半切分
  • 治的位置：快速排序划分后递归处理，最后数组已排序；归并排序先递归排序，再合并
  • 空间复杂度：快速排序 O(log n)，归并排序 O(n)
  • 稳定性：快速排序不稳定，归并排序稳定
2. 基数排序中，为什么要先按低位排序，再按高位排序？

基数排序是稳定的，所以可以按"低位优先"（LSD）的方式进行多关键字排序。先按个位排序，相等的元素保持原顺序；再按十位排序时，十位相等的元素会保持个位排序的顺序。
