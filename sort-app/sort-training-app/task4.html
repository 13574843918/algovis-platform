1 算法原理

堆排序基于大根堆（父节点大于等于子节点）。分为两个阶段：建堆（从最后一个非叶子节点开始调整）和排序（交换堆顶与堆尾，重新建堆）。

时间复杂度：O(n log n)，空间复杂度：O(1)，是不稳定的排序算法。

2 堆的存储结构

  • 节点 i 的左子节点：2*i + 1
  • 节点 i 的右子节点：2*i + 2
  • 节点 i 的父节点：(i - 1) / 2
  • 最后一个非叶子节点：⌊n/2⌋ - 1

4 Java代码实现

// 堆排序  时间: O(nlogn)  空间: O(1)  稳定: 否
public void createHeap(int low, int high) {
    if (low >= high || high >= r.length) return;
    int j, k;
    Product tmp;
    for (int i = high / 2; i >= low; --i) {
        tmp = r[i];
        k = i;
        j = 2 * k + 1;
        while (j <= high) {
            if (j + 1 <= high && r[j].price < r[j + 1].price) j++;
            if (tmp.price < r[j].price) {
                r[k] = r[j];
                k = j;
                j = 2 * k + 1;
            } else break;
        }
        r[k] = tmp;
    }
}

public void heapSort() {
    Product tmp;
    createHeap(0, r.length - 1);
    for (int i = r.length - 1; i > 0; --i) {
        tmp = r[0];
        r[0] = r[i];
        r[i] = tmp;
        createHeap(0, i - 1);
    }
}
