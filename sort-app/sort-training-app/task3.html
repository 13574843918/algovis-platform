1 算法原理

直接选择排序（Select Sort）的核心思想是：在无序区中找出最小元素，将其与无序区第一个元素交换位置，然后缩小无序区范围。

每一轮排序后，最小元素被放到有序区的末尾。

时间复杂度：O(n²)，空间复杂度：O(1)，是不稳定的排序算法。

3 Java代码实现

// 直接选择排序  时间复杂度: O(n²)  空间: O(1)  稳定: 否
public void selectSort() {
    int k;
    Product tmp;
    for (int i = 0; i < r.length - 1; i++) {
        k = i;
        for (int j = i + 1; j < r.length; j++) {
            if (r[j].price < r[k].price) {
                k = j;  // 记录最小值索引
            }
        }
        if (k != i) {
            tmp = r[i];
            r[i] = r[k];
            r[k] = tmp;
        }
    }
}

关键点：

  • k 记录无序区中最小值索引
  • 内层循环范围：j = i+1 到 n-1
  • 只在k != i时才交换

2. 选择排序是稳定的排序算法吗？请举例说明。

不稳定。举例：数组 [{A:80}, {B:60}, {C:60}]，第一轮找到最小值 {B:60}（索引1），与 {A:80}（索引0）交换，变成 [{B:60}, {A:80}, {C:60}]。两个价格60的元素相对顺序改变了。

💡 提示

选择排序每轮只需一次交换，比冒泡排序交换次数少得多。但正因为"跳跃式交换"，它是不稳定的。
