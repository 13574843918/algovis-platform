1 算法原理

直接插入排序（Insert Sort）是一种简单的排序算法，核心思想是：将数组分为"有序区"和"无序区"，每次取无序区第一个元素，在有序区从后向前查找插入位置。

将待插入元素缓存到临时变量 tmp 中，然后在循环中移动元素，最后将 tmp 插入到正确位置。

时间复杂度：O(n²)，空间复杂度：O(1)，是稳定的排序算法。

3 Java代码实现

// 直接插入排序  时间复杂度: O(n²)  空间: O(1)  稳定: 是
public void insertSort() {
    for (int i = 1; i < r.length; i++) {
        if (r[i].price < r[i - 1].price) {
            Product tmp = r[i];
            int j = 0;
            for (j = i - 1; j >= 0 && tmp.price < r[j].price; j--) {
                r[j + 1] = r[j];
            }
            r[j + 1] = tmp;
        }
    }
}

关键点：

  • 只有当 r[i].price < r[i-1].price 时才需要插入
  • 循环条件 j >= 0 && tmp.price < r[j].price
  • 插入位置是 j+1（退出循环时 j 已多减了1）

2. 直接插入排序是稳定的排序算法吗？为什么？

是稳定排序。因为算法只进行"<"比较（不含等号），当 tmp.price == r[j].price 时不满足循环条件，循环终止，tmp 插入到相等元素之后，不改变相等元素的相对顺序。

💡 提示

插入排序对"近乎有序"的数组效率很高，最好情况下时间复杂度可达 O(n)。这也是为什么希尔排序通过分组来让数组接近有序，从而提升整体效率。
